## Lessons
- Sessions must kill only the PIDs they started. A broad `Get-CimInstance … -like '*pytest*' | Stop-Process` killed a session's own Claude process.
- Probe runs need a Windows-style PYTHONPATH. A POSIX `;` list silently imports main's installed package; this gave a false 49/53.
- A full 5,000-seed probe takes about 75 min. Background tasks time out at 30 min, so split the batches.

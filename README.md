# mc-tracker

A free, open-source desktop companion for **MapleStory Classic World**. It watches your game window and tracks your session, and helps you price-check items.

> Status: early development. Screen reading is calibrated for **2560x1440 fullscreen, UI Size = Ideal Ratio** (other 16:9 resolutions likely work; others are untested).

## Features (planned)

- **EXP/hr**: live rate, time to level, session totals (handles level-ups and deaths)
- **Map**: read from the minimap name
- **Monsters**: kills counted from the EXP bar's gain (never more than it supports), split per monster by the EXP gain messages and the current map's monsters; party kills vs solo from the party widget and chat
- **Loot**: items and mesos picked up, from pickup messages
- **Items used**: potion/consumable usage from hotkey counts
- **Overlay**: frameless, always-on-top, draggable pop-out window with adjustable opacity, showing animated monster sprites and item icons
- **Price check**: hover an item and press **Alt+A** (change with `--hotkey`). The app reads the item name, copies it, and switches to your open [mesos.watch](https://mesos.watch) tab (or opens one); paste with Ctrl+V

## How it works

It only **reads pixels** from the game window (Windows Graphics Capture), like sharing your screen on Discord. It never reads game memory, modifies game files, or sends input to the game. Video never leaves your computer.

## Required game settings

- **UI Size: Ideal Ratio** (Options → Graphics)
- **HDR off** in Windows
- **Minimap map name visible**

## Calibration

`python tools/read_screenshot.py path/to/screenshot.png` prints what the reader sees (level, EXP, map, message lines). Screenshots are git-ignored; keep yours in `screenshots/`.

## Development

```sh
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[vision,dev]"
pytest
python -m mctracker          # watches the "MapleStory" window; or: python -m mctracker --demo (fake data, no game needed)
```

Sprites, icons and base item/monster/map data come from [maplestory.io](https://maplestory.io) (MapleStory Classic World `MCW/1.2` data), fetched at runtime and cached in `%LOCALAPPDATA%\mc-tracker\assets`. Extra reference data from NiaDB is fetched locally with `tools/fetch_meowdb.py` once permission is granted. It is not committed to this repo. See [docs/data-sources.md](docs/data-sources.md).

## Build the .exe

A windowed (no terminal) Windows build, made with PyInstaller as a one-folder app:

```powershell
.\packaging\build.ps1                          # clean build venv in .venv-build (installs .[vision] + pinned PyInstaller)
.\packaging\build.ps1 -VenvPath D:\Maple\.venv  # or reuse an existing venv that already has .[vision]
```

The result is `D:\Maple-dist\mc-tracker\mc-tracker.exe` (override with `-OutDir`); copy or shortcut the whole `mc-tracker` folder. It bundles Python, the OCR models and the Qt plugins, so it runs without Python installed. `python -m mctracker` still works from source.

- **Your data** stays in `D:\Maple\.mc-tracker` (same as the source build), or in `%LOCALAPPDATA%\mc-tracker` if there is no `D:\Maple`; set `MC_TRACKER_HOME` to put it elsewhere. Nothing is written inside the install folder.
- **Errors** show a message box and are logged to `<data dir>\logs\mc-tracker.log` (native crashes go to `fault.log`).
- The icon is generated by `python packaging/make_icon.py` (original art, theme colours).
